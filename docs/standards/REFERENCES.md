# Technical standards and references

- RFC 1034, RFC 1035 — Domain Names concepts and implementation.
- RFC 2136 — Dynamic Updates in DNS.
- RFC 2845 and RFC 8945 — Secret Key Transaction Authentication (TSIG; RFC 8945 updates the specification).
- RFC 3986 — URI generic syntax.
- RFC 9110 — HTTP semantics.
- RFC 8259 — JSON.
- RFC 3339 — Timestamps in internet protocols.
- RFC 2606 / RFC 5737 / RFC 3849 — Reserved example domains and addresses.

Refer to https://www.rfc-editor.org/ for authoritative RFC texts and errata. Provider APIs and behavior must be checked against current upstream documentation during implementation.
