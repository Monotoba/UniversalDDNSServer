PR #105 tests an isolated, non-root UID 65533 producer against an unrelated UID 65534 reader. The privileged CI harness only provisions file ownership and forks processes, then each drops groups and UID before publishing, accepting the Linux abstract Unix socket, and exchanging SCM_RIGHTS. The producer creates a private 0600 snapshot, the reader must fail direct pathname opens, and the reader validates and consumes the received descriptor. The socket is ephemeral and produces no pathname or ACL grant. This fixture does not create a systemd listener, broker command, deployment user accounts, or a production freshness policy. Hard deadline, FD limits, socket lifecycle exhaustion, and trusted generation freshness still need separate acceptance.
