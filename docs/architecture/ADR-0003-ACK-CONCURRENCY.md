PR #111 adds a nonblocking process-local publication acknowledgement lock. A concurrent attempt fails before altering the existing registry or publisher state, while the initial attempt finishes its own publication and acknowledgement. Isolated tests cover overlapping threads, interruption before the atomic rename, directory fsync failure and callback failure. This lock is not an interprocess synchronization primitive, does not establish a cross-process observer trust channel, and cannot make snapshot rename plus volatile issuance atomic across SIGKILL or power failure. Unknown outcome remains fail-closed upon process restart. No broker/VM/service/ACL/release changes.
