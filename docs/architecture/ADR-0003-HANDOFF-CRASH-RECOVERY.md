PR #107 adds Linux forked-process fixtures for SIGKILL of an idle handoff peer, closed connection failure, and recovery through an independent subsequent SCM_RIGHTS transfer. A separate worker-child fixture installs RLIMIT_NOFILE, RLIMIT_CPU and RLIMIT_AS and verifies parent limits remain unaffected. These are fixtures, NOT limits installed in the broker or producer services; a service runner would still need to enforce them. The tests use same-UID children; separate non-root producer/reader tests remain in the privileged Linux fixture. Kernel resource limits cannot by themselves guarantee clean SQLite shutdown or durable publication. No VM/ACL/service/broker/release changes.
