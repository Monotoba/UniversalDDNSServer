PR #104 runs an isolated privileged CI fixture on Linux/Python 3.12. The parent is UID 0 and owns a mode-0600 published snapshot in a mode-0700 directory; a forked child drops groups, GID and UID to 65534 before connecting over a Linux abstract Unix socket. The root sender authorizes the child through SO_PEERCRED and passes a read-only descriptor. The child verifies that direct opens of live SQLite and the published snapshot are denied, validates the received descriptor's producer UID and reads the generation-consistent staged counts. The fixture has a CI timeout; it neither deploys a socket service nor grants permissions to the broker. It is an acceptance check for this one host configuration, not production authentication, trusted freshness, or a hard resource bound. The ordinary unit suite skips this root-only test when running unprivileged.
