PR #106 applies a short, fixed socket timeout to the isolated SCM_RIGHTS send/receive operations, and ensures all received ancillary descriptors remain owned by cleanup logic until every check (including CLOEXEC setup) succeeds. Negative tests cover silent peers, disconnected peers, surplus descriptors with /proc/self/fd leak accounting, and receipt inheritance. These are in-process protections, not an OS-enforced deadline on all filesystem or SQLite operations. The API mutates the socket timeout; callers must use a dedicated handoff socket. No broker or VM integration; resource-limit and crash/recovery work remains.
